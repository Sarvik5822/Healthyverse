Healthyverse

Healthyverse is a health tracking application designed to help users monitor and manage their everyday wellness.

Features
Body Metrics: Track body measurements and related health metrics.
Vitals Tracking: Record and monitor vital signs.
Water Intake: Track daily hydration.
Step Tracking: Monitor daily steps and activity.
Menstrual Cycle Tracking: Log and track menstrual cycles.

Frontend: React Native
Backend: Add your backend technology here
Project Structure

The frontend and backend are maintained as separate projects.

Privacy

This application may handle sensitive health-related information. Never commit real user health records, API keys, passwords, or environment secrets to this repository.
